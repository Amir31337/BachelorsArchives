## Bachelor's Thesis Project

**Accelerating Supply Chains with Ant Colony Optimization Across a Range of Hardware Solutions**

Developed a sophisticated supply chain optimization system that leverages the Ant Colony Optimization (ACO) metaheuristic algorithm to solve complex logistics problems. The project demonstrates advanced skills in algorithm design, parallel computing, and optimization theory.

**Key Accomplishments:**
- Implemented ACO algorithm from scratch in Python to optimize multi-node supply chain networks
- Designed the solution to handle real-world constraints including plant capacities, freight rates, warehouse costs, and VMI customer requirements
- Utilized parallel processing and multi-threading to accelerate computation across different hardware configurations
- Processed large-scale Excel datasets containing plant-port relationships, order lists, products per plant, and freight rate matrices
- Integrated mathematical optimization using PuLP library alongside the metaheuristic approach
- Developed comprehensive data visualization using Plotly, NetworkX, Matplotlib, and Seaborn
- Validated algorithm performance through comparative analysis and documented results in formal academic presentation

**Technologies Used:** Python, NumPy, Pandas, NetworkX, ACO-Pants, PuLP, Plotly, Matplotlib, Seaborn, OpenPyXL, PyMetaheuristic, Google Colab, Threading, Multiprocessing

**Deliverables:** Research paper, Python implementation, Jupyter notebook, presentation slides, analytical output files

This project synthesized knowledge from operations research, algorithm design, software engineering, and data science to address a practical industrial engineering challenge.
